【这份文件是什么】
  功能蓝图（桌面《酒馆功能蓝图.txt》）现在只列已经落地的内容。
  从里面挪出来的条目放在这里，分两种：
    · 完全没做的；
    · 只做了一半的（每条都写清"已经做了什么、还差什么"）。
  条目保留原来的 [核心] / [重要] / [加分] 标注和参考链接；做完了就把它挪回蓝图。
  编号（1.4、2.6 这种）指它在蓝图里原来的位置。

【先看结论】
  完全没做的：语音（2.6 整块）、写卡工具链的几项、手感类开关、开机自启 / 托盘 / 自动更新，
  以及蓝图里自标"你还没提的"那些加分项（桌宠 / 手机端 / 导出 HTML / 多人跑团 / 机器人桥接）。
  做了一半的：提示词的预算规则与第 4 种裁剪、片段库界面、前置后置词的一次性覆盖、
  卡生成器 / 对话式改卡、云端出图、提示词缓存复用、本地小模型兜底。

 一、写卡区
====================================================================

1.2 角色卡本体
  [重要] 卡的组织 —— 还差"按来源分组（原创 / 导入）"
         已经做了：搜索、收藏、自定义标签；来源现在只是个筛选条件，没有分组展示。
  [重要] 卡版本历史 —— 还差"版本对比"
         已经做了：每次保存留一版、能回滚。
  [加分] 卡的"血统"记录：这张卡从哪来、改过哪几手。

1.3 前端（卡内 + 全局外观）
  [加分] 头像形状、消息阴影、背景图、玻璃拟态等预设风格的开关。

1.4 提示词系统
  [重要] 上下文预算 —— 还差"超预算时先砍谁、后砍谁，规则可配置"
         已经做了：能看到每段占多少 token、总量多少。
  [重要] 裁剪策略 —— 还差"把丢掉的换成小总结"和"四种策略可组合"
         已经做了：保留最近 N 条 / 保留开头 N 条 / 从中间丢，三种里选一种。
  [加分] 提示词模板市场式的本地收藏：把好用的片段存下来复用。
         备注：接口 /api/prompts/snippets 已经有了，但界面上没有入口。
  [加分] A/B 试跑：同一条消息用两套提示词各跑一次，左右对比。

1.5 前置词 / 后置词
  [重要] 前置 / 后置词 —— 还差"临时改一次、不改全局"
         已经做了：能按角色 / 按对话分别设置。
  [加分] 后置词的"强约束"开关：同时用前置 + 后置夹住，对付不听话的模型。
  [加分] 每次修改保留历史，能一键切回上一版。

1.6 世界书
  [加分] 从 URL / wiki / 文档一键生成世界书条目。
         （参考：bmen25124/lorecard、cha1latte/universal-lorebook-creator）
  [加分] 世界书 ↔ 长期记忆互转：把总结沉淀成世界书条目，反之也行。

1.7 记忆系统
  [核心] 小总结 —— 还差"每积累 N 条消息（或超过 M 个 token）就自动滚动总结一次"
         现在是小总结要手动点、或靠定时任务跑，没有自动阈值。
  [重要] 大总结 —— 还差"固定的大小上限"
  [重要] 大总结 —— 还差"手动定稿，定稿后 AI 不再自动改写"
         现在只能用"钉住"近似（钉住的会一直注入，但不是真正的定稿锁定）。

1.9 写卡工具链
  [重要] 卡生成器 —— 还差"给一张图 / 一段设定生成完整卡"
         已经做了：给一段设定，写卡助手能生成一张卡草稿。
         （参考：easychen/airole 图生卡、bmen25124/SillyTavern-Character-Creator、
           cha1latte/sillytavern-character-generator、CygnusXGithub/CharacterGen）
  [重要] 对话式改卡 —— 还差"改完先看差异，你确认才写入"
         已经做了：写卡助手能按指令直接改写字段。
         （参考：flizzywine/dsh-tavern 的对话式人物卡编辑）
  [加分] 一键去 AI 味：改写生硬的句子。
  [加分] 从网页 / wiki 抓料生成设定与世界书。
         （参考：bmen25124/lorecard、cha1latte/universal-lorebook-creator）

1.10 写卡区加分项
  - 给角色绑一个音色（后面 TTS 用），卡走到哪声音跟到哪。
    （要等 2.6 语音先做出来）

 二、玩卡区
====================================================================

2.1 基础对话
  [加分] 打字机音效、消息淡入、平滑滚动等手感开关。

2.4 叙事控制
  [重要] 重写与微调：不满意就让某一段重写，且能只改这一段。
  [加分] 思考链可见：让角色先想再答，思考过程可以隐藏也可以展示。
         （参考：cierru/st-stepped-thinking）

2.5 galgame 演出层
  [加分] 角色配音：每个角色绑一个音色，台词自动朗读。
         （要等 2.6 语音先做出来）

2.6 语音 —— 整块没做
  [重要] 语音朗读（TTS）：AI 的每条回复可以朗读出来，可只读新消息。
         音色绑定到角色，群聊里不同角色不同声音。优先接本地 TTS，省钱。
         （参考：remsky/Kokoro-FastAPI、RVC-Boss/GPT-SoVITS、
           daswer123/xtts-api-server、rhasspy/piper、Artrajz/vits-simple-api）
  [重要] 语音输入（STT）：按住说话，转成文字发出去。
         （参考：SYSTRAN/faster-whisper、speaches-ai/speaches）
  [加分] 实时语音通话式对话：说完就自动触发回复，像打电话。
  [加分] 语音消息：录一条语音当成对话消息存进历史。
  阻塞原因：要给 server/providers 加 speech / transcription 适配器；这个仓库的硬约束里
            明确"别动 server/providers/*"，所以一直挂着。提供方注册表里这两个 kind
            已经占好位置，解禁后就能接。

2.7 图片生成与素材
  [重要] 图片来源 —— 还差"云端 API"
         已经做了：本地模型（ComfyUI）+ 手动上传。
  [加分] 提示词辅助：标签超市，从常用标签里点选组合。
         （参考：wfjsw/danbooru-diffusion-prompt-builder）
  [加分] 以图搜图式的素材库管理。
         （参考：zanllp/infinite-image-browsing）

2.9 玩卡区还可以加（调研里翻到的）
  - 手机端 / 局域网访问：手机浏览器打开就能继续玩同一个对话。
    （参考：MiaoWuNYA/rikkahub-sillytavern-android、Voine/ChatWaifu_Mobile、PocketRisu/PocketRisu）
    备注：多用户模式 + 窄屏自适应已经能凑合，但没有专门的移动端体验。
  - 桌面宠物 / Live2D：把角色放到桌面上，能拖动、能说话。
    （参考：moeru-ai/airi、jofizcd/Soul-of-Waifu、inni918/warashi）
  - 主动性：角色会主动来找我说话、发消息提醒、按作息上线。
    （参考：DasterProkio/awesome-ai-companion）
  - 撤离 / 通知：生成完了给我系统通知，或者推送到手机。
    （参考：TheIronME/SillyTavernNotificationScript）
    备注：本机通知已经有了（响一下 / 浏览器通知），推送到手机没有。
  - 导出为 HTML / 电子书：把一段对话导成能发给别人看的网页。
    （参考：LenAnderson/SillyTavern-Export-HTML）
  - 好感度系统：独立的、多维度的关系数值，影响语气和态度。
    （参考：Catfish872/astrbot_plugin_favourpro）
    备注：演出层里有单维"好感度 + 阈值路线"，多维关系数值没有。
  - 多人跑团：几个人共用一个房间，我来当主持人。（参考：diceframe/diceframe）
  - 对话机器人桥接：接到 QQ / Telegram 上，在手机上也能玩。（参考：koishijs/novelai-bot）
