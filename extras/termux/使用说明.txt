========================================
 Silver Tavern 内测版 0.6.0 · 手机版（Termux）
========================================

这是给安卓手机用的。不用 root、不用装 exe —— 手机上跑一个小服务，
然后手机浏览器打开就能用。跟电脑版是同一个程序、同一种数据格式。


一、先装 Termux
---------------
  必须从这两个地方装，别用手机应用商店里的：
    · F-Droid           （推荐）
    · GitHub Releases   github.com/termux/termux-app/releases

  应用商店那个 Termux 早就停止维护了，装了会出各种莫名其妙的错。


二、把文件放进手机
------------------
  1) 先把压缩包解压到手机里，用文件管理器就行，建议解压到「内部存储 / Download」。

  2) 打开 Termux，先执行一次：

         termux-setup-storage

     手机会弹权限，点「允许」。

  3) 把解压出来的文件夹搬进 Termux 自己的目录（放这儿最快、最稳）：

         pkg install -y unzip
         cd ~/storage/downloads
         unzip 压缩包名.zip -d ~/silver-tavern

     已经用文件管理器解压过的，也可以直接搬：

         cp -r ~/storage/downloads/解压出来的文件夹 ~/silver-tavern

     搬完检查一下这两样都在：  ~/silver-tavern/源代码/server/index.mjs
                              ~/silver-tavern/移动端-Termux/安装.sh


三、安装（一条命令）
--------------------

         cd ~/silver-tavern/移动端-Termux
         bash 安装.sh

  它会自动：装 Node.js → 检查版本和 node:sqlite → 建数据目录 →
  把 `tavern` 这个启动命令装好。跑一次就够。


四、以后怎么启动
----------------

         tavern

  然后手机浏览器打开：  http://127.0.0.1:8788

  不想装 `tavern` 命令也行，直接跑：

         cd ~/silver-tavern/移动端-Termux
         bash 启动.sh


五、想让电脑也用同一份
----------------------

         TAVERN_HOST=0.0.0.0 tavern
     或者
         bash 启动.sh --lan

  它会打印一个局域网地址（形如 http://192.168.1.23:8788）。
  同一个 WiFi 下的电脑打开就能用 —— 而且用的是**同一份数据**。


六、几个常用的
--------------
  换端口        TAVERN_PORT=8899 tavern
  关掉          在 Termux 窗口里按 Ctrl+C
  数据在哪      ~/silver-tavern-data
                （换手机就把整个文件夹拷走，master.key 一定要一起）
  老被杀后台    先执行一次 termux-wake-lock；Termux 通知栏里也能开
  更新          用新的「源代码」文件夹覆盖旧的，数据不动


七、要注意的
------------
  · 模型要自己配：进「模型接入」填你自己的 API Key，或者本地模型的地址。
    手机上跑不动本地大模型，要接就跑在别的机器上（填那台机器的局域网地址）。
  · 出图：手机上可以连你自己电脑上的 ComfyUI，填电脑的局域网地址就行。
  · 别把数据目录放在 /sdcard（权限、性能都差），就放 Termux 家里。
  · 手机版和电脑版的数据是**两份**。要来回搬，用「工具箱 → 备份与维护」
    的全量备份 / 加密备份，或者直接拷 ~/silver-tavern-data。

遇到问题先看 Termux 窗口里的报错 —— 那边写得比界面详细。

 用之前请看压缩包里的「使用须知.txt」。
