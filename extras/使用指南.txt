========================================
 Silver Tavern 内测版 0.7.1 · 使用指南
========================================

（这份是给 Windows 电脑用的，照着往下做就行。）

包里有什么
----------
  SilverTavern.exe    程序本体，双击就能用（不用装 Node，也不用装别的）
  使用指南.txt        就是本文件
  使用须知.txt        用之前先看这个（一页，30 秒）
  移动端-Termux/      手机版（安卓）：装 Termux 之后跑里面的「安装.sh」，看同目录的使用说明
  源代码/             完整源码（想自己改就改，怎么跑起来见里面的「怎么改.txt」）
  LICENSE             AGPL-3.0 开源许可证（法律要求附上）
  NOTICE.md           第三方组件说明（含从 SillyTavern 移植的部分）

整个过程大概 3 分钟，其中大部分时间是等模型配置填完。


用之前先看一眼（重要）
----------------------
  这是个空壳工具：不带模型、不带任何内容。写什么、出什么图，都归你自己管。

  · 仅限成年人自己用。
  · 不要生成、传播违法内容 —— 涉及未成年人的是红线，"是 AI 画的"不是理由；
    拿真人（熟人、同学、同事、公众人物）套进去生成不雅内容，也是明确的违法。
  · 生成的东西自己留着看是一回事，发出去、转发、发群里、卖，是另一回事。
  · 作者只给工具，不提供任何内容，也不参与你用它产生的东西，后果由使用者自负。

  完整版在「使用须知.txt」里，建议花一分钟过一遍。


换电脑怎么办（备份与搬家）
--------------------------
  你的东西全在 exe 旁边那个 data\ 文件夹里：数据库、素材、备份、
  和一个 master.key（模型密钥是用它加密的）。

  · 换电脑：把整个 data\ 文件夹拷到新电脑上 exe 旁边就行。
    注意 master.key 一定要一起拷 —— 丢了它，之前填的模型密钥就解不开了。
    拷之前先把程序关掉（免得数据库还在写）。

  · 更稳的做法：界面上「工具箱 → 备份与维护 → 一键全量备份」，
    它会打成一个 zip（数据库 + 素材）；新电脑上装好程序，用同一页的
    「恢复」把它导进来。这一步不挑机器，Windows 之间搬最省事。

  · 想把数据加密带走（连主机管理员也解不开）：同一页的「加密备份」，
    导出一个 .stbk 文件，用你自己给的口令加密，换机器 / 换服务器都能导入。

  · 别把 data\ 放进网盘同步目录（OneDrive / 坚果云那类）再让两台机器同时开 ——
    数据库会写坏。真要两台共用同一份数据，就让其中一台当主机，
    另一台用浏览器连过去（见下面「远程访问」）。


一、怎么运行
------------

1) 先把压缩包解压到一个空文件夹里。
   重要：不要直接在压缩包里双击 exe，会导致数据文件散落到临时目录、关掉就没了。
   操作：右键压缩包 →「全部解压缩」→ 选一个空文件夹 → 解压。
   建议解压到这样的位置：D:\SilverTavern\  （路径里最好别有特殊符号）

2) 打开解压出来的文件夹，双击 SilverTavern.exe。

3) 会弹出一个黑色窗口（命令行窗口）。
   这个黑窗口就是程序本体，别关它！
   关掉黑窗口 = 关掉程序。

4) 打开浏览器（Edge / Chrome 都行），在地址栏输入：

       http://127.0.0.1:8788

   回车，就能看到界面了。
   （地址里的 127.0.0.1 就是"这台电脑自己"，8788 是端口号。别用搜索引擎搜它。）


二、Windows 会拦你，这是正常的
------------------------------

第一次运行，Windows 大概率会弹出蓝色的「Windows 已保护你的电脑」。
这是因为这个 exe 没有花钱买数字签名，不是病毒。处理办法：

    点「更多信息」 → 点「仍要运行」

杀毒软件（360、火绒、Windows Defender 等）也可能拦截或报"未知程序"，
同样是"没签名"导致的误报，允许 / 信任即可。

如果被杀软直接删掉了，把它加进信任区，或者暂时关掉实时防护再运行一次。


三、你的数据存在哪
------------------

第一次运行后，程序会自动在 exe 所在的文件夹里建一个 data 文件夹，
里面装着你的所有东西：

    角色卡 / 世界书 / 预设     （写卡区的数据）
    对话记录 / 场景状态         （玩卡区的数据）
    素材 / 图片
    配置和密钥（master.key 等）

想换电脑，直接把这个文件夹整个拷走就行（连 exe 一起拷最省事）。
想备份，也是拷这个 data 文件夹。


四、配模型（必须做，否则没法聊天）
----------------------------------

程序本身不带 AI 模型，需要接一个你自己的模型服务。步骤：

1) 进入左侧的「模型接入」。
2) 点「添加提供方」。
3) 填三项：
     - 接口地址：一个"兼容 OpenAI 格式"的地址，例如
         https://api.openai.com/v1
       或你自己用服务商给的地址（DeepSeek、通义、月之暗面、硅基流动……
       只要它说"兼容 OpenAI 接口"就行）。
     - API Key：你自己账号里的密钥（形如 sk-xxxxxx）。
     - 模型名：要调用的模型名字，例如 gpt-4o-mini、deepseek-chat 等，
       用你那个服务商文档里写的名字。
4) 保存后，把它「设为默认」。

也支持本机跑的模型：如果你自己装了 Ollama 或 LM Studio，
地址一般填 http://127.0.0.1:11434/v1（Ollama）之类，同样当 OpenAI 兼容接口填。

注意：这一项需要你自己有一个模型服务的账号和 Key，程序不会替你提供。
模型服务通常是按用量单独计费的，跟这个软件无关。


五、怎么关掉程序
----------------

直接关掉那个黑窗口（点右上角的 ×，或在窗口里按 Ctrl+C）。
关掉后浏览器里的页面就打不开了，这是正常的。
下次用的时候，再双击一次 SilverTavern.exe 就行。


六、觉得界面卡 / 切换要点半天，怎么办
--------------------------------------

先说明：界面本身不重，卡一般是"浏览器没在用显卡画界面"造成的。
按顺序试这三步，基本都能解决：

1) 打开浏览器的"显卡加速"。
   Edge：右上角 … → 设置 → 系统和性能 → 打开「可用时使用图形加速」，重启浏览器。
   Chrome：右上角 ⋮ → 设置 → 系统 → 打开「使用图形加速功能（如果可用）」，重启浏览器。

2) 想确认到底有没有开成：
   地址栏输入  edge://gpu  （Chrome 是  chrome://gpu），
   看 "Composition"（合成）那一行是不是 Hardware accelerated。
   如果显示 Software only，就是没开成 —— 老驱动 / 虚拟机 / 省电模式都可能这样。

3) 还是卡，就打开软件自带的「低配模式」：
   左侧「设置」→ 界面 → 勾上「低配模式（关掉毛玻璃和背景动画）」→ 保存。
   它会去掉界面上的毛玻璃和背景动效，在老机器 / 虚拟机 / 远程桌面上会明显顺很多。
   （界面会稍微朴素一点，功能完全一样。）

另外，笔记本插着电、关掉"省电模式"也有帮助；浏览器窗口开小一点、缩放保持
100%，也会轻不少。


七、出问题了怎么反馈
--------------------

把下面三样发给我，我基本就能定位：

1) 出问题的地方截个图（网页上的报错 / 卡住的地方）。
2) 那个黑窗口里最后几行文字（可以直接从窗口里框选复制，或截图）。
3) 你 exe 旁边那个 data 文件夹（打包发给我，方便看日志和状态）。

安全提醒：千万不要把你的 API Key 发给我，也不要发到群里。
截图的时候记得把 Key 那一串打码。data 文件夹里可能有密钥文件，
发之前如果不放心，可以先把里面的密钥相关文件删掉再发。


八、已知"还没做"的功能（别当 bug 报）
-------------------------------------

以下功能目前是故意没做的，属于未完成项，不是坏了：

  - 语音：TTS（朗读）/ STT（语音输入）都没做。
  - 标签超市：还没有。
  - 以图搜图式的素材管理：还没有。
  - 多用户 / 登录 / 账号体系：单人自用不需要，直接忽略即可。

除此之外，写卡区、玩卡区、工具箱（ComfyUI、花费统计、月报 / 年报、任务中心、MCP、备份）都已可用。

十、想给手机 / 别的电脑用（远程访问）
--------------------------------------
  默认只有"本机"能打开（地址里的 127.0.0.1 就是本机的意思）。
  想让手机或另一台电脑连过来，按情况选一种：

  1) 同一个 WiFi（局域网，最常见）
     启动之前先设一个环境变量，让它监听所有网卡：

         在命令行里：  set TAVERN_HOST=0.0.0.0
                       SilverTavern.exe

     然后在手机上打开：  http://这台电脑的局域网IP:8788
     （IP 用 ipconfig 看，形如 192.168.1.23；第一次防火墙会弹窗，选"允许访问"。）

  2) 不在同一个网络（在外面也想连回来）
     不要用端口转发把端口直接暴露到公网。用 Tailscale 这类 VPN 最省事：
     两台设备都装上、登同一个账号，然后用它分配的那个地址访问。
     （Cloudflare Zero Trust / ngrok 也行；只要走公网，务必配 HTTPS。）

  3) 想几个人长期共用一个服务
     启动时加一个参数： SilverTavern.exe --multi-user
     第一次打开首页会先让你建管理员账号（就是你自己），之后在
     右上角「🛡️ 主机管理」里给每个人开账号。一人一个独立数据目录，
     互相看不见。

     先说清楚：账号口令只提供"用户之间的基本隐私"，不是安全功能 ——
     数据在这台电脑上是明文存的，能碰到硬盘的人都能看能改。
     所以别跟不信任的人一起用。

  4) 或者：手机上自己跑一个（不用电脑开机）
     压缩包里有个「移动端-Termux」文件夹，照着里面的「使用说明.txt」做就行 ——
     装个 Termux，手机就是一个**独立的**酒馆（数据也是独立的一份，
     和电脑那份互不影响；要互搬用「工具箱 → 备份与维护」）。
